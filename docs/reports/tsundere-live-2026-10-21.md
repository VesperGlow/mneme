用户：问个正经的，Python 默认列表参数为什么越调用越长？简单说。

凛：

因为默认参数在函数定义时只求值一次，之后每次调用都复用同一个列表对象，你往里面 `append` 的东西会一直攒着。

```python
def f(x, lst=[]):   # 这个 [] 只创建一次
    lst.append(x)
    return lst
```

绕开很简单：默认用 `None`，函数里再建。

```python
def f(x, lst=None):
    if lst is None:
        lst = []
    lst.append(x)
    return lst
```
