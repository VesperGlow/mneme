# Mneme 使用控制与时间上下文改进（2026-10-23）

本轮实现停止生成、确认遗忘、自动备份，以及每轮交流间隔。时间行为按最终要求保持为资料：沿用当前时间和时区，只增加距最后完成交流的间隔秒数，没有新增跨日标记、话题切换规则、每日重置或额外模型请求；原有角色和摘要提示保持原样。

## 行为

- 网页及刷新后恢复的生成可停止；API 提供 `POST /v1/turns/{id}/cancel`；QQ `/停止` 在验签、账号检查和去重后直接取消当前轮次，不排在长生成后面。
- 取消与完整回复提交通过 SQLite 事务竞争，已完成回复保留。取消的部分回复不写入正式助手历史、不触发提取，已记录用量保留；运行中的本地推理等待和工具循环被中断。已经发出的外部请求或浏览器动作可能完成。
- 遗忘先展示最多 12 条候选，用户选择后确认；预览五分钟有效。版本变化、未审阅 ID、生成中、上下文变化均拒绝确认；多条删除在一个事务里执行，有冲突全部回滚。确认支持同内容幂等重放。
- 遗忘范围为仅移除长期记忆，或同时清空摘要并停止使用此前全部对话作为聊天历史；其他长期记忆保留。原始消息、修订、审计与备份保留。已屏蔽的共享来源不会通过另一条记忆的引文再次进入提示，也跳过后续提取请求。
- 完整安装启用每日私有备份定时器，保留 14 份成功快照；每份含数据库、配置和 SHA-256 清单。发布前在独立临时数据库验证恢复、外键和表行数；失败不触发旧备份清理。原生 WAL、恢复失败、覆盖拒绝、权限及保留策略由本地 SQLite 实测覆盖。
- 交流间隔直接读取原始消息，压缩摘要的更新时间不会重置间隔；失败或取消轮次不被当成已完成交流。下一轮重新读取最近完成记录，无新增持久化状态。

## 质量评估边界

保留既有五套独立出题的冻结记忆数据，新增运行前 SHA-256 与题量校验；单套 blind 运行未达到既有质量门槛时返回失败。对话评估新增计划状态、原句与助手解读区分、未知事实范围场景，保存用例及哈希；恢复运行时拒绝混用不同用例、模型和二进制。

本环境缺少 Podman 及完整离线模型服务，本轮仅完成冻结数据完整性校验，未执行真实记忆质量盲测或真实供应商自然度评估，不报告召回率或自然度提升。真实质量验收入口仍为：

```bash
python3 scripts/memory-e2e.py --deepseek-relay --split blind5 \
  --require-quality --output artifacts/memory-blind5-current
```

该命令要求另行启动既有隔离测试中继和模型服务，不读取生产对话或生产数据库；已用于诊断的套题不得再次称为新盲测。只校验冻结数据可执行：

```bash
python3 scripts/memory-e2e.py --verify-fixtures-only --output artifacts/fixture-integrity
```

验证命令包括 Rust 全目标测试、严格 Clippy、格式检查、Python 常规测试、新增控制浏览器测试及既有完整 Console 浏览器回归。控制测试采用真实 Axum/SQLite 和本地流式上游，覆盖取消与完成竞争、工具等待中取消、用量保留、QQ 账号隔离及重复回调、遗忘回滚和共享来源隔离；不向真实 QQ 账号发送测试消息。

最终本地结果：Rust 124 通过、0 失败、12 默认忽略；Python 53 项中 49 通过、4 个真实模型依赖项跳过。严格 Clippy、rustfmt、JavaScript/Python/Bash 语法、systemd 单元验证及 diff 检查通过。真实 Chromium 的新增控制流程与完整 Console 回归均通过，包含 390px 布局。Python 依赖和 Playwright 仅安装在 `/tmp` 下的隔离检查环境，未改变项目运行时依赖。
