# 中文语言规范与验收（2026-10-20）

按用户最终选择，内置 Agent 指令和新生成的行为配置统一使用简体中文。英文探索仅发生在本地和隔离副本，没有推送或部署生产；不因记忆语言推断英文或中文必然表现更好。此次选择优先考虑当前中文对话、中文记忆和人工维护的一致性。

## 范围和边界

- 主对话、记忆提取及摘要指令原本是中文，保留原实现。
- 人格编译器升至 v5，明确 description、basis、signals 使用中文；旧画像保留历史，标记待更新，通过现有接口重新生成缓存，不增加逐轮调用。
- 自主反思的新规则、解释和审查说明使用中文，锁定项和证据原文不改。
- 表情识别的 system 和图片说明统一中文，名称、描述均生成中文；保持名称 40 字符、描述 120 字符上限，以及既有一次精简重试和用量统计。
- 浏览器工具的自然语言说明改为中文；工具名称、参数、枚举、URL、JSON 字段及模型预处理约定保持原协议。
- 用户原始人格、历史消息、事实记忆、专名、证据引文及外部资料保留原文。生产原始人格本身含英文，不擅自翻译或改写。
- WebUI 的 HTML、JavaScript 和 CSS 未改变，标签、按钮、布局保持中文。

主要修改位置：`src/persona.rs`、`src/evolution.rs`、`src/stickers.rs`、`src/llm.rs`、`services/tools/catalog.json`；复用原有 API、缓存和表情存储，不新增表、规则引擎或模型服务。

## 存量数据处理

生产预备份位于 `/home/o721/mneme/acceptance/prompt-chinese-20261020/`，包含在线 SQLite backup、原始有效配置、表情元数据及服务配置；发布切换另做冷备份和逐行摘要核对。

20 张存量表情名称本来就是中文，保留名称、图片、ID、启用状态和历史引用，只按现有画面含义将英文描述译为中文。使用现有编辑接口逐项保存，保留翻译前后清单；不重新识别全部图片，不覆盖图片或记忆。生产画像通过正常生成接口更新，保留旧画像；不导入隔离环境的测试对话、反馈或进化规则。

## 验证
