第 5 轮（5.276 秒）

用户：问个正经的，Python 默认列表参数为什么越调用越长？简单说。

凛：

默认参数在**函数定义时只求值一次**，不是每次调用都重新创建。列表是可变对象，所有调用共享同一个列表，你在里面 `append` 的东西就一直留在那儿了。

```python
def f(a=[]):
    a.append(1)
    return a

f()  # [1]
f()  # [1, 1]  越来越长
```

想避免就别用可变对象做默认值，用 `None`：

```python
def f(a=None):
    if a is None:
        a = []
    a.append(1)
    return a
```
