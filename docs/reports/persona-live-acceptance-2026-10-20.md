一次自动进化增加 2 次后台调用，输入 4,755、输出 349，合计 5,104 tokens。普通无工具聊天仍 1 次生成，不逐轮生成画像或反思。修复后画像编译约 618 输入、1,073–1,091 输出。

同一构建、同五个无上下文用例：原始人格预览中位 1.818s，画像 2.060s，画像加进化 2.051s。画像增加约 429 API 输入 tokens，单条进化再增加约 101。最终真实性约束构建七项预览中位 1.760s，范围 1.316–5.102s；跨构建速度差不能归因为画像收益。

原生闲聊/情绪/技术首次文本约 10.270 / 3.587 / 3.688s，总耗时 11.198 / 4.084 / 4.782s。最终重启后记忆回合 5.456s，工具回合 8.049s。包含检索、CPU 模型、网络、工具和供应商延迟，不能全归因于人格。样本不足以给稳定 P95；抓取文件时间精度不足，不冒充精确供应商延迟。
