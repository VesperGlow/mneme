Mneme 极简人格驱动精简与消融（2026-10-21）

已完成代码精简：运行时只读取用户保存的角色背景，没有人格编译、行为决策、自动反思或独立心理状态。临时连续信息留在原始历史和现有压缩摘要，近期已召回的有效事实保留为来源上下文。没有新增模型、依赖或框架，没有部署或修改生产数据。

基线是在实施前保存的当前完整工作区，包含此前尚未提交的改造，不能用 Git HEAD 冒充。源码195个文件在 artifacts/minimal-persona-baseline/source.tar.gz，逐文件哈希在 manifest.json，原工作区补丁在 working-tree.patch，可执行文件为 mneme-before。相对这份基线的实际生产代码/配置变更在 baseline-to-final.patch；src、web 和默认配置合计净减少 1631 行（不含测试、文档与二进制）。默认角色的表达字段也缩短，已经存入 SQLite 的用户人格不被自动替换。

审计没有发现独立的意图分类器或情绪评分模型，也没有代码硬性要求每轮必须关心或追问，因此不把它们说成已删除的现有功能。原画像并非每轮重新生成；实际删除的是持久扩写层与后台反馈触发的自主调整。移除自主写人格能力后，只有现有认证下的用户编辑入口能修改角色背景，预览不写入角色、历史或记忆。

旧数据处理：六维画像、进化版本和旧临时笔记保留，不自动转为新背景；旧修改/生成/反思入口返回410。GET /v1/console/persona/archive 可查看归档，GET /v1/console/persona/context 可查看实际 Prompt，预览使用 message/source_hash/use_context。原始人格 PUT、历史、记忆、工具与认证接口保留。旧迁移不删除，也没有新增迁移；旧 interaction_state 表只供归档/清理，不再写入或参与生成。GET /v1/console/persona/state 现在展示既有摘要与旧笔记归档，DELETE 只清除旧笔记，不清除摘要或对话。

模型和测试条件固定为 deepseek-flash、temperature=0.7、max_tokens=4096、context_tokens=100000，使用此前用户授权的同一提供商凭证。每组29轮，覆盖闲聊、知识问答、矛盾更正、跨日相对时间、拒绝建议、长期记忆延续、独立偏好和工具，再重复此前八轮傲娇探针。每个场景独立数据库，场景内连续；时间测试把首轮来源消息移到两天前，检查“明天”的来源锚点。基线原始人格与最终相同；基线显式导入此前 DeepSeek 已生成的六维画像，进化笔记为空。没有重新编译画像挑选更好的基线。

| 场景 | 基线与最终的实际观察 |
| --- | --- |
| 闲聊/情绪 | 两版都能短答和拒绝建议时停住，没有固定分析清单；最终八轮探针出现了更多括号动作和语气舞台描写，不能宣称自然度全面提升 |
| 知识与格式 | Python 可变默认参数解释正确；两处只答6×7均得到42。最后知识回答没有添加可拆卸的人设尾句，但不保证其他采样也如此 |
| 矛盾/偏好 | 本轮更正后的住址得到承接；对故事结局的偏好能在用户持相反意见时维持，并分别回溯双方偏好 |

| 记忆 | 仅删提示的早期变体在追问时无来源，反而否认了纸桥；补回近期有效来源后最终三轮都保留纸桥，不再否认。未知宠物名没有猜，但个别轮仍说“你没跟我说过”，超过缺少证据能支持的范围 |

这里实现的是更小、更稳定的生成架构；没有用自然度分数或挑选台词把模型剩余的刻板反应包装成已经解决。少约束让模型更自由，也会放大模型对“傲娇”的刻板表达，这是本轮消融的真实结论。
